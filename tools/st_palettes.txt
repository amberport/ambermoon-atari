# st_palettes.txt -- hand corrections for the ST palettes
#
# The build (tools/st_palettes.py build, called by tools/build_st.sh)
# reduces every palette of the game to 16 registers like St_bauen does at
# run time and writes the result to ATARI/AMBFILES/STPAL.DAT; the ST loads
# that file once at start (docs/17-deviations.md, D1).  This file holds only
# what differs from the computed result.  Look first, then correct:
#
#   python3 tools/palette_editor/palette_sheet.py -> build/palette_editor/index.html
#   build/st_palettes/listing.txt                 every palette in numbers
#
# Both contain Thalion's colours and graphics and stay in build/.
#
# One correction per line:
#
#   <palette> colour <c> <r>     Thalion colour c (1..31) into register r (1..15);
#                                the register values are recomputed as the
#                                mean of their colours
#   <palette> ste <r> <RGB>      register r on the STE (and Falcon): three hex
#                                digits 0..F, e.g. A84
#   <palette> st <r> <RGB>       register r on the plain ST: three digits 0..7;
#                                without this line the ST shows the upper
#                                three bits of the STE value
#   <palette> method <m>         how the palette is grouped: "unweighted"
#                                (St_bauen as at run time; the default
#                                without this line) or "weighted N" (by how
#                                many points of each colour the game shows,
#                                every colour at least N %, 1 without N);
#                                choose with the buttons of the palette
#                                editor's page; either may end in "oklab":
#                                colour distances in OKLab, hue counting
#                                double, instead of RGB (e.g. "weighted 1
#                                oklab"; build time only, St_bauen stays RGB)
#   <palette> own <c> [<c> ...]  these colours (1..25) form a register of
#                                their own, no other colour joins it; a
#                                colour of the same value goes with them;
#                                one line per register
#   <palette> ramp <n>           Thalion's UI ramp 26..31 takes at most n
#                                registers (1..5, default 5); the rest go to
#                                the map colours
#
# The palette editor's page sets method, own and ramp lines by click and
# shows the result at once.
#
# <palette> is one of
#   pal N        Palettes.amb N (maps, event pictures)
#   combat N     Palettes.amb N with colours 26..31 from Tactic_pal (combat picture)
#   main         Main_pal (top of the screen, inventory)
#   tactic       Tactic_pal (combat, tactic field)
#   automap      Automap_pal
#
# A hand value holds for the full palette.  While Thalion fades or dims (3D
# light levels), the ST scales it per channel with the faded colours of its
# group (st_regs_bauen), so the fade still ends in black.
#
# Example (not active):
#   pal 2 colour 17 9
#   tactic ste 3 666
#   tactic st 3 333
